# REVLiP
Instant replay pour gamers : appuie sur F8, garde les 30 dernières secondes.

⬇️ **Télécharger :** [dernière version](https://github.com/nuvoracloud-code/revlip-releases/releases/latest) → `REVLiP-Setup-x.x.x.exe`

Windows 10/11 64 bits. Si Windows affiche « Windows a protégé votre PC » :
clique sur « Informations complémentaires » → « Exécuter quand même ».
